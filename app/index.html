Prototype Cohort Harmoniser

Wellbeing · digital media use · proximate context, across 12 longitudinal studies, read against the digital world of each country and year (the “invisible room”)

Prototype – not a validated resource. This harmoniser is a working prototype that needs further improvement and independent checking. Construct assignments are candidates from a keyword screen of each study’s data dictionary, not verified mappings; no measurement equivalence has been tested; some dictionaries are incomplete (see Sources & gaps). Check every item against the study’s own documentation before using it in analysis, a paper or a funding application. It uses study metadata only, not participant data.

The invisible room: the digital space each wave was collected in, which the cohort studies themselves leave largely unmeasured. These are country-year (and, for Australia, state and remoteness) opportunity indicators, not anyone's exposure. Pick an age to see which room each study's young people were in when they reached it.
